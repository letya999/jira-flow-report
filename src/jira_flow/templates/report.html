Отчёт проекта

1. Пропускная способность

1.1. По людям

Число завершённых задач каждого исполнителя по неделям.
Задачи считаются по исполнителю на конец периода; повтор в одной неделе учитывается один раз.

1.2. По типам задач

Какой объём завершения дают баги, истории и задания.
Высота столбца = число разных задач, вошедших в конечный этап на этой неделе.

1.3. По бизнес-приоритетам

Распределение завершений по бизнес-приоритету на конец периода.
Число задач каждого приоритета за неделю; пустое поле показано отдельной группой.

1.4. Среднее за полную неделю

Неделя начинается в понедельник · . Бледные столбцы — неполные недели. Конечный этап задан в конфиге; другие статусы категории Jira Done, включая Rejected, не добавляются автоматически.

3. CFD

Число задач на каждом этапе во времени

3.1. По колонкам доски

3.2. По отдельным статусам

Толщина полосы — число задач в статусе; её рост показывает накопление очереди.
Статус восстанавливается по переходам; Done = запас на дату минус запас в начале. Старые статусы без ID отдельно.

3.3. Среднее число элементов в каждой колонке доски

Среднее количество задач, одновременно находящихся в колонке доски.
Сумма «число задач × длительность состояния» / длительность периода; Done здесь показан без вычитания.

4. Aging time

Длительность завершённых прохождений ·

4.1. По колонкам, с разбивкой по людям

4.2. По статусам, с разбивкой по людям

Показаны статусы из конфига. Исторические статусы сохранены в JSON и CFD.

4.3. Соотношение средних Aging time по колонкам

Средние в точности совпадают с таблицей 4.1; колонки расположены в порядке доски, без Done.
Ширина = среднее колонки / сумма показанных средних. У колонок разные выборки; их сумма не является общим сроком задачи.

5. Глубина декомпозиции

5.1. По людям

Среднее число непосредственных дочерних задач показывает, насколько дробят задачи; задачи без детей дают ноль.
Среднее = сумма числа детей / число задач. Глубина: 0 — нет детей, 1 — дети, 2 — дети и внуки; берём самый длинный путь.

5.2. Открытые задачи без декомпозиции с возрастом выше среднего

Кандидаты на разбиение: время задачи в текущем статусе выше среднего для задач, вышедших из него.
Для каждой задачи складываем только её заходы в этот статус.

6. Время в статусе

До четырёх самых долгих открытых задач на статус · порядок доски справа налево

Показывает, сколько времени открытая задача провела именно в своём текущем статусе.
Складываем время всех её заходов в этот статус, включая текущий заход до среза.
